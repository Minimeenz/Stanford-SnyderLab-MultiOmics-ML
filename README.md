# Stanford School of Medicine

Computational work conducted at Stanford School of Medicine, organized by lab and project.

## Projects

- **[Snyder-Lab-fPOP](./Snyder-Lab-fPOP)** — Familial Personal Omics Profiling (fPOP) pipeline for an epilepsy family study, Department of Genetics (Snyder Lab), directed by Dr. Michael Snyder. Proband vs. family multi-omic analysis spanning genomics, proteomics, epigenomics, immune profiling, chromatin accessibility, virome, and single-cell multiome.

> **Privacy note:** All projects in this repository contain pipeline code and directory structure only. No sample identifiers, patient data, PHI, or real omics/sequencing data are included anywhere in this repo.
